# CANOE_Log_Pare
我的CANOE太贵，没有CANOE的时候怎么方便查看CANOE日志，使用这个软件，类似CANOE Trace窗口功能软件，可以解析CANOE日志，查看和过滤，导出等功能。

### 新增功能

#### 1. 折叠控制
- 点击分组头部可折叠/展开
- 显示分组内报文数量
- 支持键盘快捷键

#### 2. 系统消息分类
- 系统变量：黄色背景
- 测试框架：蓝色背景

#### 3. 增强的过滤功能
